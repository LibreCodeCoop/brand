# Color system

## Core historical identity

The 2021 visual identity manual specifies:

| Role | Pantone | CMYK | RGB | Digital reference |
|---|---|---|---|---|
| Primary red | 485 C | C5 M95 Y95 K0 | 229 51 42 | #e5332a |
| Primary gray | Cool Grey 9 C | C55 M45 Y45 K10 | 124 123 123 | #7c7b7b |
| Supporting light gray | Cool Grey 2 C | C15 M10 Y15 K0 | 219 219 219 | #dbdbdb |

The archived primary SVG uses RGB 229/51/42 and 124/123/123, matching the manual.

## Current digital system

The current LibreCode website still uses `#e5332a` as its named red token, confirming continuity for the signature red.

The website also defines a broader dark/light UI palette for digital surfaces. Those tokens are a **digital design-system layer**, not automatically core logo colors.

## Rule

Do not collapse Pantone, CMYK, RGB, and HEX into a claim of exact cross-medium equivalence. The manual should state the documented references and explain that production output may require calibrated conversion/proofing.

Issue #7 tracks reconciliation of the historical visual identity with the current digital design system.
