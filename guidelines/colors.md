# Color system

## Brand colors

| Role | HEX | RGB |
|---|---|---|
| LibreCode Red | `#e5332a` | 229, 51, 42 |
| LibreCode Gray | `#7c7b7b` | 124, 123, 123 |
| LibreCode Light Gray | `#dbdbdb` | 219, 219, 219 |

These are the current canonical brand references.

For print production, use a color-managed workflow and proof the output for the target process. Screen values and print values are not assumed to be physically identical.

## Digital UI

The website may define additional semantic tokens for surfaces, text, interaction, focus, success, warning, and error states. Those tokens belong to the product/site design system and must satisfy accessibility requirements.

The signature brand red remains `#e5332a`.
