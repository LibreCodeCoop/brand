# Digital design system

The digital design system is the implementation layer of the LibreCode brand.

## Typography

- Display: Space Grotesk
- Body: Instrument Sans

## Core brand token

- Brand red: `#e5332a`

## Implementation rule

UI systems may define additional semantic and surface tokens without changing the logo contract. Changes to the logo, official name, or core brand colors require an explicit brand-system change.

Accessibility is mandatory for all interactive and textual uses.
