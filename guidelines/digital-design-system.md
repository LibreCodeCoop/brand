# Digital design system relationship

This document resolves the relationship between the historical visual-identity manual and the current LibreCode website.

## Decision

The brand system has distinct layers.

### Core identity

Stable unless explicitly redesigned:
- official naming;
- logo geometry and symbol;
- signature red `#e5332a`;
- approved gray/monochrome/reversed logo applications;
- clear-space and minimum-size rules;
- trademark usage.

### Historical editorial identity

The 2021 manual specifies **Krona One**. It remains part of the documented history and may be used where an intentional legacy/editorial expression is desired, but it is **not mandatory for the current website**.

### Current digital typography

The current website design system is authoritative for web UI:
- display: **Space Grotesk**
- body: **Instrument Sans**
- fallbacks remain implementation details of the site.

### Current digital palette

The website extends the core red into a larger accessible dark/light UI palette. Those tokens are digital interface colors and do not redefine the logo palette.

## Governance rule

A future website redesign may evolve UI typography and semantic tokens without constituting a logo/brand redesign. Changes to core identity require explicit brand-system review and a major brand release.

The public manual should label historical, core, and digital rules clearly rather than presenting all of them as one immutable layer.
