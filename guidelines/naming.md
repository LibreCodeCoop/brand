# Naming

Use **LibreCode** for the brand/product name and **LibreCode Coop** for the cooperative identity.

## Correct
- LibreCode
- LibreCode Coop

## Avoid
- Librecode
- Libre Code
- libreCode
- LibreCode Co-op

The repository, website, documentation, presentations, press material, and UI copy should use the official spelling consistently.
