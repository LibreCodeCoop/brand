# Approved assets

This directory contains approved public exports generated or validated from canonical source material.

Consumers should normally use files from here rather than `source/` or `archive/`.

Each asset must be covered by REUSE/SPDX metadata and documented in the asset inventory.


## Generated derivatives

The canonical public artwork master is stored under `source/artwork/`.

PNG and PDF derivatives are generated in CI rather than manually edited. This avoids drift between duplicate exports and makes the transformation reproducible.

Official artwork is covered by `LicenseRef-Brand-Asset` until the complete copyright chain is verified.
